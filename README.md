# IT Support Ticketing System

## Project Overview
The IT Support Ticketing System is a web-based application developed using Bubble.io. The system enables users to create, manage, and track IT support tickets through a centralized dashboard.

## Features
- Ticket Creation
- Ticket Management
- Workflow Automation
- Dynamic Status Tracking
- Database Integration
- Dashboard Monitoring

## Technologies Used
- Bubble.io
- Bubble Database
- GitHub
- Workflow Automation

## System Workflow
1. User creates a support ticket.
2. Ticket data is stored in the database.
3. Workflow automation processes the request.
4. Ticket status is updated.
5. Dashboard displays ticket progress.

## Ticket Status
- Open
- In Progress
- Resolved

## Testing
The application was tested for ticket creation, database storage, workflow execution, and status updates.
